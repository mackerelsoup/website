## Agent skills

### Issue tracker

Issues live in GitHub Issues (mackerelsoup/website), via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Workflow

### Branching

Before making any changes to resolve an issue, ticket, or bug report, create and switch to a new branch first. Never commit issue-resolution work directly to `main`.
